Instrucciones importantes:
  • El archivo puede ser .xlsx, .xls o .csv
  • Para archivos CSV, usar punto y coma (;) como separador
  • La primera fila debe contener los encabezados (será ignorada)
  • Las columnas deben estar en este orden exacto:
Columna Campo Ejemplo Requerido
A patente DYSS52 Sí
B marca Peugeot Opcional
C modelo Partner Opcional
D año 2012 Opcional
E tipo Funcional Flota o Camion DTS Opcional
F flota FLOTA SUC STA MARTA Opcional
G kilometraje 154152 Opcional
H activo SI o NO Opcional
Notas importantes:
  • Los valores #N/D o vacíos se ignorarán
  • Si la patente ya existe, el vehículo se actualizará
  • Los tipos de vehículo válidos son: Funcional Flota, Camion DTS, Camion Cstore, MERCHANDISING
Ejemplo de formato:
patente;marca;modelo;año;tipo;flota;kilometraje;activo
DYSS52;Peugeot;Partner;2012;Funcional Flota;FLOTA SUC STA MARTA;;SI
FHHT10;Kia;Frontier;2012;Camion DTS;#N/D;;NO
GWXK64;Hyundai;Porter;2014;Camion Cstore;FLOTA SUC STA MARTA;154152;SI
